🍗 Tiệm Gà Rán Của Hưn
Game mô phỏng quán gà rán chơi trên trình duyệt — không cần tải, không quảng cáo.

🎮 Cách chơi
**Sáng:** Nhập gà, bột, dầu, hộp + chọn vị gà và món kèm
**Bán:** Lấy hộp → chọn vị → chiên gà đúng lửa → thêm món kèm → bóp sốt → giao
**Tối:** Xem sổ sách, lên cấp, mở khoá món mới

🌶️ Cấp sốt
0 (không cay) → 7 (cay xé lưỡi)

🍗 10+ vị gà
Truyền thống, cay Hàn, mật ong, bơ tỏi, sả ớt, phô mai, tiêu đen, phô mai tuyết, sốt Hàn, BBQ
